Simulations

Simulations module provides you with “What-If” functionality, helping to understand, the impact of changes, made to roles, transactions and users on overall SAP security.

While Reports module provides you with an overview and analysis of the actual situation, using Simulations you can analyze scenarios when users’ privileges  are changed or internal roles structure is altered. Thus, Simulations module helps you to simulate and eventually avoid authorization related violations across your SAP systems.

Using the left frame you can select:

  • Language  for texts
  • Object – simulation type and its parameters

Open the Language dropdown and select a language for text display:

To run a Simulation you should select an object and its value(s) by manual input or by clicking on the button at the right side of the field to open the Search Help functionality. Depending on the chosen object (Simulation type) there can be either multiple os single choice of parameter values.

Note
Search Help is a full-scale module covered separately.

Click <Go> button to run the simulation. The initial result, appeared in the right frame will display object’s actual state. Now you can start making changes, to simulate the impact:
