Analytics – Top Users with Actual SOD Violations

Top Users with Potential SOD Violations analytic panel provides information about users with most potential SOD violations, based on a chosen version of Actual Violations (by SoD Rules) report. By default in a new installation of  SoDA™ this panel appears empty and should be configured as described further below. In case if it is already configured, the panel displays a horizontal bar chart. Each bar represents the quantity of actual violations for a user:

To analyze relations between the Roles and other SAP entities, click on the role ID.

Note
Where-Used is a full-scale module covered separately here.

To open the popover with users detailed data click on a bar or the total number of users:

Data in the popover can be sorted and filtered using the table header, as anywhere across the systems. The data can be also exported to Excel:

To analyze relations between the user and other SAP entities, click on the user ID.

Note
Where-Used is a full-scale module covered separately here.

To get complete information about the user, its privileges and more, click on the icon near its ID. Information popover will display user’s information, properties, roles, profiles, t-codes and user groups to which the user belongs:

If you need to adjust the panel’s settings and manage variants – click on the <…> button and then on the <edit> button to open the settings panel at the right side of the frame. If you have a brand new installation, the panel will appear empty and that will be your first step in populating it with data:

You can choose between 3 options of date ranges. For options 2 and 3 you should enter the values manually:

To choose a Report and Reporting Instance click the icon at the right corner of the field. Then you’ll be able to choose one from a popover. 

Note
Reporting Instances must exist in the system when you configure this panel. That means that the report must be run beforehand.

To select the number of displayed users, enter the value in the Top N input field.

If you want to clear the values use the <Clear> button.

Please refer to the Overview section for information about managing variants.
