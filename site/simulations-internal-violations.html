Internal Violations – Parameters

Internal Violations simulation allows you to  analyze internal SoD violations inside Roles. The simulation checks for the SoD collisions between the T-Codes, assigned to the Role. First, you can check for the violations of original Role’s state, then you can extend the simulation by adding new T-Codes to it.

Multiple Roles can be added to the simulation screen. All Roles will be checked at once as per simulation run.

Using the uppermost toolbar in the right frame you can:

  • Expand/Collapse the display
  • Switch between Roles
  • Add new Roles to your analysis
Expand/Collapse

By clicking on the <Add role> button a popover will be displayed, offering you to:

  • Add an existing role
  • Simulate creation and consequent violation check of a brand new role, which currently doesn’t exist in your SAP system:

If you choose adding a New Role, it will be displayed blank within a new tab, waiting T-Codes to be assigned. You can add and manage T-Codes, filters and eventually Run Simulation. These actions are covered in detail further in this section of the document.

If you choose adding an Existing Role, the Search Help popover will be displayed, helping you to find Role/s.

Note
Search Help is a full-scale module covered separately.

Using the toolbar above the table with T-Codes you can:

  • Clear filters
  • Clear Sort
  • Add T-codes (using Search Help functionality)
  • Delete chosen T-Codes
  • Reset T-Codes to an initial state
  • Check where else the Role is used (using Where Used functionality)
Clear filter

As anywhere across the system, you can click on the table’s header to access filtering and sorting of table’s content:

You can change/select new using direct input or Search Help functionality:

Where Used functionality is available for each T-Code, and to the entire role:

Once you’ve changed the T-Codes (by adding or deleting them), you can compare the changed New State against the Initial State:

Filters can be applied via the Simulation Filters Bar, located at the lower part of the frame. Its header contains buttons for Show/Hide the bar, Clear  filters and Run Simulation:

To filter by SoD Rules you can enter them directly or click on the button at the right corner of the field to open the popover and to select the desired Rules from the list:

To filter by SoD Rule Severity choose the values from the dropdown:

To filter by T-Codes you can enter them directly or click on the button at the right corner of the field to utilize the Search Help functionality:

Once you have the simulation parameters adjusted, click on the <Run Simulation> button to get the result.
