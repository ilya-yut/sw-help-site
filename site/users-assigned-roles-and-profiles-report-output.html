User’s Assigned Roles and Profiles – Report Output

 

The upper part of the frame shows the Parameters values, entered before the run, the lower part displays the collected data:

 

Report output contains the following fields:

  • User
  • Full name
  • Entity Type
  • Entity Id
  • #of T-Codes
  • #of Users
  • Last logon date
  • Valid from
  • Valid through
  • User’s type
  • User’s Group
  • User lock status

Filters with values, entered, can be shown in detail and exported to Excel. Filters that were not applied, are marked with “*”  (all values) and are not clickable.

To display detailed data about entered parameter values, you can click on a chosen filter and the relevant popover will be displayed:

The lower block of this screen presents the report’s output. The table displays users’ details, conflicting T-Codes, found via SoD Rules. To navigate an manage f the output, display field names and filter by Critical Objects use the buttons in the toolbar above the table, use table’s header to filter, export to PDF and Excel using the buttons at the frame footer:

When you click the <Export to Excel> button, all the report data will be exported to a spreadsheet (.xlsx file). 

When you click the <Export to PDF> button a popover will be displayed. Here you can choose which fields to export, to avoid exporting less important information to a printable PDF file. To do so, you can uncheck any field using the checkboxes:

You can display any of the report’s rows in a popover by clicking on the leftmost column icon  against the desired report row. It is convenient to look at all the data without scrolling and additionally you can export data to Excel:

To analyze relations between the user and other SAP entities, click on the user ID.

Note
Where-Used is a full-scale module covered separately here.

To get complete information about the user, its privileges and more, click on the icon near its ID. Information popover will display user’s information, properties, roles, profiles, t-codes and user groups to which the user belongs:

The displayed data can be exported to Excel, sorted and filtered. For Roles and T-Codes you can also check where else they are used:
