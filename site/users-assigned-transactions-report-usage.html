User’s Assigned Transactions – Report Usage

About:

User’s Assigned Transactions reporting function module allows you to create a wide range of reports (Reporting Instances in Skywind SoDA™ professional language) to analyze Transactions assigned to Users including User data and Transactions usage. This report helps you to manage Users’ priviledges more efficiently and avoid potential Security risks.

 

How to use:

To create a new Reporting instance, click the <Create> button and the right frame will display the report’s parameters that you have to fill. Note, that mandatory parameters have a thin red border. You don’t have to fill up all of the mandatory parameters, but at least one of the mandatory parameters must be filled.

Using the buttons in the right frame’s header and footer you can perform various actions:

  • Expand/Collapse the frame 
  • Clear Report Parameters
  • Create (Save) the Reporting Instance

For information about each parameter click the Question mark icon on the right side of parameter’s name.

Start creating a reporting instance by filling the Reporting Instance Name field.

 

Parameter block: “General”

Source System – monitored SAP source system.

Language for texts – Language to be presented by fetched texts and descriptions. The descriptions will not be filled, if chosen language is not maintained in the SAP source system. You can choose from a wide range of languages using the dropdown:

 

Parameter block: “Rules”

You can run the Reporting Instance based on SoD rules and/or individual T-Codes.

SoD Rules – SoD Rules, by which the report will be restricted, while searching for the violations. When not filled, the parameter is ignored (all SoD Rules are taken into account).

To choose SoD Rules click the icon at the right corner of the field. The Search Help popover will be displayed. Search Help is an advanced search engine, helping Skywind SoDA™ users to find desired objects in an extremely quick and flexible manner. 

Note
Search Help is a full-scale module covered separately. Alternatively, you can add the desired T-Codes directly, by hand or copying them from the Clipboard.

To remove all chosen SoD Rules, click the <Select/Deselect All> button. 

Note
Alternatively, you can add the desired values directly, by hand or copying them from the clipboard

Parameter block: “Critical Objects”

Filter by Critical Groups – critical groups, by which the report will be restricted, while searching for the violations. When not filled, the parameter is ignored (all values are taken into account).

To choose Critical Groups click the icon at the right corner of the field. To deselect all chosen values, click the <Select/Deselect All> button. Alternatively, you can add the desired values directly, by hand or copying them from the clipboard:

Filter by Critical T-Codes – Critical T-Codes, by which the report will be restricted, while searching for the violations. Each of 3 options performs its type of check:

  • Only Critical T-Codes – selects data when Critical T-Codes exist strictly on both sides.
  • No Filters – no filters for Critical T-Codes are applied.
